# Сверка на противоречия

**Источник правды:** `docs/game-flow.md` и `docs/config/balance.json`. Всё остальное сверяется с ними.

**Где искать:** `docs/*.md`, `docs/screens/README.md`, `docs/design/src` (только последний слой правок, см. ниже), `frontend/src` (тексты и `api/mock.ts`), тела открытых issues (`gh issue view N -R Stepami/golden-mouth`).

## Шаги

1. `git pull`. Скачать тела открытых issues во временную папку.
2. **Контрольная проверка поиска:** найти фразу, которая точно есть (например «Мира ответит ещё» во `frontend/src`). Не нашлась → поиск сломан (в этой среде `grep` бывает подменён и молча падает на кириллице, а zsh не разбивает список файлов в переменной). Искать Python-скриптом.
3. **Числа скриптом:** каждое правило из `game-flow.md` против ключа в `balance.json` (посты, рост, залёт, провалы, уровни, отношения, заруба, серия, уведомления, миры). Печатать OK / РАСХОЖДЕНИЕ.
4. **Контракты скриптом:** эндпоинты `backend-spec.md` §11 против `frontend/src/api/client.ts`, `app/log.ts`, `app/analytics.ts`; события `analytics.md` против вызовов `track / event / tap` в коде. Шаблонные строки и тернарники дают ложные срабатывания: каждое расхождение проверить глазами.
5. **Смысл глазами:** прочитать `game-flow.md` целиком и найти утверждения, которые спорят между собой или с другими файлами. Типовые ловушки: старые числа (посты, ×1,5, неделя зарубы, «охват на подписчика»), замки миров, род в системных текстах, жёстко прописанный мир во фронте вместо `worldOf(player.world)`.
6. **Исторические слои:** в `docs/design/src/journey_v3…v7.py` старые значения перекрыты поздними правками. Это не противоречие, если итоговый PNG в `docs/screens` верный.

## Результат

Таблица «правило / где противоречит (файл:строка) / исправление», отдельно ложные срабатывания и исторические слои. Исправить, `.github/scripts/check-secrets.sh --all`, `cd frontend && npx tsc -b && npm run build`, PR со ссылками на задачи и слить.
