# Лайки и личные отметки — frontend #302 / PR #303

Подключён контракт backend #306 в текущем дизайне production. Временная база PR — `issue-301-post-likes`, frontend diff не содержит backend-изменений. После мержа и выкладки #306 вернуть базу #303 на master; до этого frontend на прод не выпускать.

## Поведение

Компактная кнопка «♡ 42» использует существующий `.react`. Число — подтверждённые `Likes + LikedBy.Count`, сердце — личная отметка текущего игрока. Отметки бесплатны и доступны при 0 энергии. Новая подтверждённая отметка анимируется, reduced motion учитывается.

Кнопка подключена к результату публикации, ленте, каналу и треду. «Я → Отмеченные» читает серверные страницы отмеченных постов всех авторов выбранного мира, сохраняет возврат из треда и убирает карточку после снятия отметки. Прежнее содержимое профиля остаётся в «Обзоре». Есть загрузка, ошибка/повтор и пустой список.

После потерянного ответа toggle не повторяется: состояние подтверждается чтением. Старое чтение списка отменяется при обновлении подтверждённых данных; поздние AI-комментарии не стирают отметку. Ответ другого мира/аккаунта не переносится в текущий экран. Подтверждённые действия отмечаются существующим `tap.to=post_mark`, без текста поста и без смешения с автоматическими лайками.

## Принятая механика backend

Владелец продукта принял #306: автоматические лайки — сохранённые округлённые вверх 2–10% просмотров, включая миграцию исторических постов. Прежнее обнуление истории и прямая связь с качеством/залётом заменены этим решением. Frontend не пересчитывает данные и не меняет правила вероятности залёта.

## Проверки раннего контракта

- На Mini: TypeScript/Vite build и 14/14 существующих frontend-тестов. В имеющихся проверках мапперов удалено ожидание временной суммы «🔥 + ручные отметки»; новые тесты в репозиторий не добавлялись.
- App и generated SDK на контролируемых HTTP-ответах: запрос автора/мира, 0 энергии, двойное нажатие, независимый счётчик аудитории, список/открытие/возврат/снятие, пустое состояние, потерянный ответ без replay, offline/retry, 14 записей с пагинацией, поздний ответ после смены мира, ширины 320/390/430/1280.
- Настоящий HTTP API #306 в отдельной QA-БД: обычный протокол входа с полностью сгенерированными тестовыми Telegram/JWT ключами, как в TestSessionFixture. Реальные bot tokens и реальные пользователи для входа не использованы. На подготовленной тестовой записи проверены mark/unmark/list, нулевая энергия, неизменные лайки/навыки/кристаллы и изоляция другого мира.
- Собранный App + SDK в браузере через этот API, без подмены HTTP: отметка сохраняется, читается в профиле/треде и после перезагрузки, снимается из личного списка; счётчик аудитории не меняется.
- Создание публикации в новой QA-БД упёрлось в её vector index `NOT_STARTED`/`PENDING`; операции отметок проверены на фикстуре. Расчёт публикации отдельно покрывает backend CI #306. Полный путь реального Telegram-пользователя и физический телефон не проверялись.

## Окончательный контракт после мержа #306

Frontend сведён с master после #306: используется единый GET /posts, переключение через POST /posts/{postId}/like с ответом 204 и последующее чтение поста для подтверждения. Запрос отмеченных передаёт полный состав авторов мира (игрок и звёзды), likedBy игрока и выбранный worldId; включает посты персонажей и не смешивает экземпляры миров. Backend и generated-клиент сохранены точно по слитому master. Прежние проверки и снимки выше относятся к раннему контракту; актуальные результаты сверки указываются в PR #303.
