# Выбор LLM для русскоязычной игры

Исследование от 05.10.2026 для задачи #9. Игра генерирует контент только на русском языке. Значения стоимости и доступность моделей — снимок конфигурации провайдера на дату исследования, а не постоянный контракт.

## Что проверено

- Провайдер работает через LiteLLM API 1.100.4 и предоставляет OpenAI-compatible Chat Completions и Responses API.
- В Chat Completions заявлены `tools`, `tool_choice`, `parallel_tool_calls` и `response_format`.
- В доступном каталоге было 95 моделей, из них 83 модели в режиме chat прошли фильтр `healthy_only`.
- Каталог и метаданные читались с серверной авторизацией. Адрес провайдера и токен не фиксируются в репозитории.
- Для runtime остаётся `Microsoft.Extensions.AI.IChatClient`; конкретный OpenAI-compatible клиент подключается в Infrastructure.

Задача представляет собой короткую генерацию с ограниченным набором функций, поэтому для MVP достаточно `IChatClient`. Agent Framework понадобится только при появлении многошагового цикла с результатами инструментов.

## Кандидаты

Стоимость указана в расчётных единицах провайдера за 1 млн токенов. Сравнивать нужно относительную стоимость: валюта и тариф могут измениться на стороне провайдера.

| Модель | Вход | Выход | Контекст | Function calling | Вывод |
|---|---:|---:|---:|---|---|
| `gigachat3-10b-a1.8b` | 12,2 | 12,2 | 262k | да | Дешёвый русскоязычный кандидат; качества для персонажей пока не подтверждено |
| `gpt-oss-20b` | 5,888 | 27,4965 | 131k | да | Дешёвый тариф, но reasoning может съесть короткий лимит ответа |
| `deepseek-v4-flash` | 18,5318 | 37,0758 | 1M | да | Бюджетный fallback; для игровых вызовов нужен non-thinking режим |
| `gpt-4o-mini` | 29,463 | 117,852 | 128k | да | Предсказуемый технический fallback, но дороже DeepSeek |
| `gigachat3.5-432b-a28b` | 96,22 | 288,6 | 262k | да | Основной кандидат: русский диалог без лишних reasoning-токенов |
| `gigachat3.5-432b-a28b-reasoning` | 96,22 | 288,6 | 262k | да | Для редких сложных задач, не для каждого поста |

Для типового хода с 1500 входными и 250 выходными токенами GigaChat 3.5 примерно в 5,8 раза дороже `deepseek-v4-flash` по тарифу провайдера. У reasoning-варианта фактический разрыв может быть выше из-за токенов рассуждения.

## Ограниченный smoke-тест

Из-за лимита бюджета выполнено только два коротких запроса без повторов:

- `gpt-oss-20b` исчерпал лимит 180 выходных токенов с `finish_reason: length` и не дошёл до tool call;
- `deepseek-v4-flash` завершился сетевым таймаутом со стороны прокси; повтор не выполнялся.

Это не является сравнительным eval качества. Результат показывает, что reasoning-модели нельзя считать дешёвыми только по тарифу токена: для короткого игрового ответа они могут потратить лимит до формирования полезного результата.

## Решение

Решено 05.10.2026:

1. Основная модель MVP — `gigachat3.5-432b-a28b` без reasoning. Для игры только на русском качество диалога, характер персонажа и естественность коротких реплик важнее минимальной цены токена.
2. Бюджетный fallback — `deepseek-v4-flash` в non-thinking режиме. В MVP переключение выполняется конфигурацией `Llm__Model`, без автоматического повторного вызова другой модели.
3. `gigachat3.5-432b-a28b-reasoning` не вызывается на каждом ходе. Её можно отдельно рассмотреть для создания мира, длинной сюжетной сводки или разбора противоречивой памяти.
4. `gigachat3-10b-a1.8b` остаётся кандидатом на дешёвые фоновые реплики только после предметного eval.

## Контракт интеграции

- Модель выбирается конфигурацией, а не условием в доменном коде.
- Обычный ход выполняется без reasoning; задаются явные `Temperature` и `MaxOutputTokens`.
- Действия звезды возвращаются только через `react`, `comment`, `repost`, `dm`, `start_event`.
- Аргументы tools и структурированный результат проверяются серверной JSON Schema. Для строгой схемы все поля обязательны, а `additionalProperties` равен `false`.
- Результат модели остаётся недоверенным вводом: неизвестные действия и поля отклоняются, числа экономики игнорируются.
- Смена модели требует небольшого предметного eval на русских примерах: соблюдение схемы, выбор разрешённого инструмента, голос персонажа, безопасность 14+, длина ответа, latency и число токенов.
- В логах разрешены только имя модели, latency, usage, finish reason и код ошибки — без prompt, текста игрока, ответа модели и токена.
