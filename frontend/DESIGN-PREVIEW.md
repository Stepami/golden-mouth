# Посмотреть дизайн «Рек» v8

Этот режим нужен для ревью интерфейса и флоу. Работают настоящие React-компоненты приложения с отдельными демонстрационными данными. Бэкенд, Docker, Telegram, ключи и `.env` не нужны. Мокапа телефона нет.

## Запуск

Нужен Node.js 22.20.0 (версия также указана в `.node-version`). Из корня репозитория:

```sh
git fetch origin
git switch issue-205-v8-frontend
cd frontend
npm ci
npm run design
```

Откроется `http://127.0.0.1:4173/design.html`. Если браузер не открылся автоматически, перейдите по этому адресу. Для изменения порта: `npm run design -- --port 4174`.

## Что пройти

1. Приветствие → возраст → интересы → каталог.
2. Мир → обложка и завязка → направления и до трёх предпочтений → рекомендованный персонаж и образ.
3. Задание → лента → свой текст → отправка → исчезающая капсула результата → обсуждение и ответ.
4. Профиль, серия, цели, энергия, кристаллы, смена мира и сохранённые миры.
5. «Компоненты» в верхней панели: значки, загрузка, ошибка, пустое состояние, публикация, уведомления, ресурсы и крупный текст.

Верхняя панель помечает просмотр как **дизайн-превью**. Кнопка «Начать заново» очищает только данные этой демонстрации. Состояние сохраняется в браузере; закрытие вкладки его не удаляет.

Ответы персонажей заранее подготовлены, числа иллюстративные. Текст не отправляется в AI; начисления, модерация, серверный таймер восстановления и сюжетный зачёт этим режимом не проверяются. В браузере работает отдельный демонстрационный таймер +1 энергии за 10 минут. Настоящий API в этом режиме не вызывается; неподдержанные действия не переключаются на сервер.

## Статическая сборка

```sh
npm run design:build
npm run design:preview
```

Результат — `dist-design/`. Его можно отдать любому статическому веб-серверу и открыть `/design.html`; запуск через `file://` не поддерживается. Это отдельная сборка: обычный `npm run build` сохраняет интеграцию с настоящим API и не включает дизайн-фикстуры.

## Проверка девяти замечаний к PR 261 · 09.11.2026

Для новых сценариев нажмите «Начать заново» либо создайте новый мир: старые сохранённые прохождения не переписываются. Источники ролей, навыков и заданий — утверждённые четыре пакета в `docs/redesign/short-cycle/`. «Школа чародеев» остаётся самостоятельной прежней версией рядом со «Спасти Хогвартс».

- Выберите «Легче шутить»: первыми идут «Последние инфобизеры». Через настройку интересов выберите другое направление. «Показать все миры» сбрасывает фильтры.
- Внутри «Последних инфобизеров» направление «Юмор» рекомендует Бургера. «Все навыки» содержит только навыки ролей этого мира; выбрать можно от нуля до трёх. У роли остаются свои три навыка, включая своего героя. Все пять ролей видны с подписями; сетка вмещает больший состав без обрезки.
- У Изабеллы первое задание — ответить Эдуарду после спасения. Цели всех ролей доступны для чтения, без редактирования.
- В панели просмотра выберите «Пример хода». «Частичный прогресс» показывает +24 подписчика, +10 процентных пунктов одному навыку и 12,5% истории; повтор той же части не даёт рост. «Подписчики, без роста навыков» — +24 и ноль по всем навыкам. «Задание выполнено» — следующий из четырёх шагов, «Ушло 8 подписчиков» — отрицательная динамика. Это специально выбранные примеры, не оценка текста и не утверждённый баланс. Пост и ответ используют тот же пример.
- Откройте профиль, выйдите из мира, войдите в другой и вернитесь: изменения подписчиков, три навыка и прогресс истории сохраняются отдельно по каждому миру. Восстановление энергии общее.
- Общий профиль показывает нейтральную иконку, имя из первого созданного мира и ник на основе полного уникального случайного ID аккаунта. Имя фиксируется в локальном профиле; профиль персонажа ведёт к выходу в каталог.

### Граница серверной интеграции

Новые имена навыков не привязываются к прежним числам `brave/humor/topic`. Опциональные поля UI-модели `roleSkills`, `campaignProgress`, `lastTurn` заполняет только отдельный дизайн-адаптер. При отсутствии новых данных обычная сборка показывает «—», не выдумывает нулевой рост, процент или завершение. Серверные DTO и generated-клиент не менялись. Нужны отдельные серверные данные о прогрессе, навыках и идентичности аккаунта для синхронизации между устройствами. Стабильная первая роль хранится на этом устройстве; для существующего аккаунта начальное имя берётся из первого элемента полученного списка миров.
