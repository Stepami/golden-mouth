# Уведомления: события и результаты

Решено владельцем продукта 11.11.2026, Refs #205. Актуальное решение заменяет прежние уведомления о самостоятельных новых постах NPC. Polling удалён; старые `npc-post` исключены из списка и бейджа. Публикации NPC остаются в ленте. Бот и серверная история этим изменением не добавляются.

## Переключатель

«События / Результаты» использует общий `ViewFilter` из `ui/FeedFilter.tsx` и те же токены/состояния, что «Все / Мои посты». Две равные области нажатия, светлый активный текст с подчёркиванием, muted для неактивного, минимум 48 px, клавиатурный фокус, масштаб текста 200%, reduced motion. Образцы находятся на экране `#system`.

## События

Общий компонент — `ui/ActivityItem.tsx`.

- Ответы NPC, реакции на свои посты и серия; прочие существующие события сохраняются. Самостоятельные посты NPC не являются событием.
- Заголовок — максимум две строки, фрагмент ответа/своего поста — максимум три строки с многоточием. Полный текст — в исходном обсуждении.
- У реакций отдельная видимая строка «Реакций: N»: число из серверных данных своих постов. Сохранённый фрагмент относится к тому же `postId`. Если старый фрагмент недоступен, это явно указано. Имён лайкнувших нет.
- Прочитанная запись остаётся в списке, маркер исчезает только после успешного открытия публикации. Серия открывает подробности серии.
- Старые `npc-post` не участвуют в количестве непрочитанных даже до очистки локального хранилища.
- Нового фонового polling ленты нет. При открытии уведомлений обновляются подтверждённые реакции/ответы своих постов через существующий API.

## Результаты

Общий статичный компонент `PublicationResult` используется в `publication/ResultHistory.tsx`: он раскрывает аудиторию, навыки, показанную награду и переход к публикации. Баннерный `ResultIsland` в истории не монтируется.

- Тип «Пост / Комментарий», дата и время, фрагмент собственного текста до трёх строк; новые ходы сверху.
- История локальна для аккаунта и прохождения: ключ `reki:v7:<account>:results:<world>`.
- Дедупликация по `actionId`, а не `postId`. Повтор/поздний refresh обновляет тот же ход на прежней позиции. Первоначальные before, дата, текст и показанная награда остаются неизменными; after дополняется подтверждёнными значениями.
- Награда — устойчивый снимок, не пересчёт от сегодняшнего кошелька. DEV +2 помечены «Превью: за ход»; production отбрасывает preview. Чтение истории, раскрытие и переход в тред ничего не начисляют, не запускают прилёт кристаллов и вибрацию.
- Пятисекундное автоскрытие относится только к баннеру. История остаётся после его закрытия и reload, без произвольного лимита и тихого удаления старых записей.
- При ошибке записи показываем «История результатов не сохранена»; новые записи доступны в памяти вкладки, без обещания сохранения после её закрытия.
- Старый единственный receipt переносится, если доступен. Без даты/текста показываем «Время не сохранено» / «Текст этого хода не сохранён», не создаём вымышленную предыдущую историю.

Серия в шапке по-прежнему открывается целиком по нажатию; подробная карточка остаётся в профиле. Приёмка: 320/390/430 px, desktop и текст 200%, без горизонтального переполнения, с видимым фокусом. Проверка с изолированным API не означает проверку live AI или основного аккаунта.
