# Проверка #297

Скриншоты настоящего текущего интерфейса в headless Chrome с изолированным API и синтетическим аккаунтом. Числа и комментарии на этих картинках — управляемые QA-состояния, не результаты production и не обещание удержания.

Ручной проход: происхождение ownWords при правках, пробелах, очистке, отмене, перезагрузке и смене игрока/мира; одинаковый флаг в API и post_publish; одна публикация; обычный/минус/залёт/ноль/ожидание/ошибка; переходы, выбор адресата, сохранение нового черновика при позднем AI, нативный share и Telegram fallback с текстом этого поста; 320/390/430/1280 px. Проверка энергии перед отправкой сохранена.

Отдельно на настоящем QA backend с изолированной БД и настоящими ML-клиентами: на hard посторонний текст с ownWords=false получил «В тему» и прирост +45 без бонуса своих слов; самостоятельный посторонний текст сохранил оценку «Не в тему», минус −1 и бонус своих слов. QA-аккаунт и его миры/посты удалены. Это проверка правил, а не повторный расчёт пользовательской выборки. В .NET проверено равенство каждому порогу и ближайшее меньшее float-значение.

Редизайн изменён и проверяется отдельным PR от актуальной интеграции #284; его стили не переносятся в текущий интерфейс. Новые тесты в репозиторий не добавлялись. Физические телефоны и production этим проходом не использовались.

Дополнительно проверены текст 200% на 320px без горизонтального скролла и закрытие Escape.

Существующая фикстура world-drafts обновлена с устаревшего balanceKey на действующий templateId; число и сценарии тестов сохранены.
