# Посмотреть дизайн «Рек» v8

Этот режим нужен для ревью интерфейса и флоу. Работают настоящие React-компоненты приложения с отдельными демонстрационными данными. Бэкенд, Docker, Telegram, ключи и `.env` не нужны. Мокапа телефона нет.

## Запуск

Нужен Node.js 22.20.0 (версия также указана в `.node-version`). Из корня репозитория:

```sh
git fetch origin
git switch issue-205-v8-frontend
cd frontend
npm ci
npm run design
```

Откроется `http://127.0.0.1:4173/design.html`. Если браузер не открылся автоматически, перейдите по этому адресу. Для изменения порта: `npm run design -- --port 4174`.

## Что пройти

1. Приветствие → возраст → интересы → каталог.
2. Мир → обложка и завязка → три навыка → персонаж и образ.
3. Задание → лента → свой текст → отправка → исчезающая капсула результата → обсуждение и ответ.
4. Профиль, серия, цели, энергия, кристаллы, смена мира и сохранённые миры.
5. «Компоненты» в верхней панели: значки, загрузка, ошибка, пустое состояние, публикация, уведомления, ресурсы и крупный текст.

Верхняя панель помечает просмотр как **дизайн-превью**. Кнопка «Начать заново» очищает только данные этой демонстрации. Состояние сохраняется в браузере; закрытие вкладки его не удаляет.

Ответы персонажей заранее подготовлены, числа иллюстративные. Текст не отправляется в AI; начисления, модерация, таймер восстановления и сюжетный зачёт этим режимом не проверяются. Настоящий API в этом режиме не вызывается; неподдержанные действия не переключаются на сервер.

## Статическая сборка

```sh
npm run design:build
npm run design:preview
```

Результат — `dist-design/`. Его можно отдать любому статическому веб-серверу и открыть `/design.html`; запуск через `file://` не поддерживается. Это отдельная сборка: обычный `npm run build` сохраняет интеграцию с настоящим API и не включает дизайн-фикстуры.
