# Результат публикации и происхождение текста — #297

Решение владельца от 13.11.2026. Рабочая база — интеграция #284 (`codex/205-dev-integration`, e390b8a), поверх review #279. Это отдельная ветка редизайна, без переноса его стилей в текущий production.

Действующие визуальные источники в этой базе: `frontend/src/v7/design-tokens.json`, `frontend/src/v7/night.css`, компоненты `frontend/src/v7/ui` и `docs/reviews/redesign-dev-2026-11-11.md`. Исторический `docs/redesign/DESIGN-SYSTEM.md`, упомянутый в frontend/AGENTS.md, в этой базе отсутствует; номера старых PR не использовались как признак актуальности.

После любого сохранённого поста, включая минус и залёт: компактное «Пост опубликован», имя и аватар персонажа, реальный комментарий до разбора, фактический знак прироста/0, краткое объяснение, «Разбор поста», «Новый пост», «Комментировать», менее заметное «Поделиться». Пятисекундное автоскрытие результата поста убрано. История использует ту же карточку без повторных эффектов. Ожидание и ошибка комментария не отменяют публикацию и не блокируют закрытие/новый пост. Поздний комментарий дополняет соответствующий результат в истории и треде, не открывая их принудительно.

× возвращает в канал (лента с фильтром «Мои посты»). «Новый пост» открывает существующий редактор и сохранённый черновик; энергия проверяется прежним путём. «Комментировать» открывает существующий тред конкретного поста, далее сохраняются выбор NPC-комментария и стоимость ответа. «Поделиться» использует настоящий referral API и нативный Telegram/браузерный сценарий; для Stories используется существующая карточка именно этого postId. Демонстрационных чисел, ответов и фиктивного успеха нет. Историческое решение #205 «шеринг убран» заменено только для результата поста.

ownWords — происхождение черновика: вставленная идея false до фактической полной очистки или «Очистить». Частичные правки и пробелы не возвращают true; ручной ввод совпадающего текста не делает false. Флаг сохраняется с черновиком и одинаков в POST и post_publish. Для false Topic=1, без сравнения с идеей; для true пороги easy/normal/hard 0.35/0.45/0.55. Другие причины минуса и безопасность независимы, бонус своих слов при false отсутствует. Старые результаты не пересчитываются. Фоновая генерация #264 не дублируется.

Для обязательного backend CI перенесён уже действующий в master pin транзитивного Microsoft.AspNetCore.WebUtilities к действующей в master версии 10.0.15. У старой базы семейство MicrosoftExtensionsVersion равно 10.0.14, поэтому для этой единственной зависимости закреплена разрешённая версия явно. Базовый #284 останавливался на NU1902 для 2.3.0; остальные зависимости и уровень проверок безопасности не меняются.
