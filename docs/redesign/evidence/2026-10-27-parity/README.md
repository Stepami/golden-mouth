# Сверка с актуальным HTML-прототипом — #205 / PR #219

27.10.2026. Chromium, 390×844, light/dark, reduced motion. Проверки выполнены в отдельном локальном frontend, общая DEV-сборка не синхронизировалась.

Снимки: [вход](welcome.png), [Лера](guide.png), [каталог нового игрока](new-worlds.png), [профиль](profile.png). Сценарные данные — изолированные ответы текущих HTTP-контрактов в браузере, не пользовательский аккаунт. Матрица состояний: [matrix.json](matrix.json); переходы: [transitions.json](transitions.json).

Визуально сравнены со свежим HTML: композиция первого экрана/крупного фото, тексты и отступы, возрастной барабан, шаги Леры, карточка своего мира, категории и карточки каталога, общая навигация, лента, редактор, история и профиль. Первый экран и Лера сняты после правок. Согласие на обработку данных и серверная граница 14+ сохранены; в HTML-прототипе согласие отсутствует.

Общий HUD в профиле/истории показывает существующие ресурсы. Игровой день, кристаллы, подарки и сюжетные чекпоинты из #221 не реализованы. Вместо диктовки карточка своего мира предлагает текстовую настройку. Известная обложка пресета показана в профиле; для неизвестного экземпляра остаётся нейтральный fallback, происхождение не определяется по названию.

20 состояний в двух темах: все без горизонтального переполнения, ошибок рендера и незагруженных изображений. Переходы включают ограничение 14+, согласие, оба шага/возврат/пропуск Леры, фильтрацию каталога, обзор/персонажа/настройки, обсуждение, черновик, результаты и настройки профиля.

Живой API в этом проходе не использовался: локальный порт backend недоступен. Это проверка клиента и отображения, а не генерации, серверной атомарности или сохранения в общей БД. Реальную DEV-интеграцию нужно повторить после отдельно согласованной синхронизации.
