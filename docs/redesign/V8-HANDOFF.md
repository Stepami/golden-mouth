# Передача фронта v8

Refs #205. Продолжение frontend PR #234; база — `issue-205-v7-release`. Пакет содержит дизайн, флоу, общие компоненты, токены и ассеты. Сервер, миграции, инфраструктура, мокап устройства и видеозапись сюда не входят.

## Просмотр

[Запуск без бэкенда](../../frontend/DESIGN-PREVIEW.md): `cd frontend && npm ci && npm run design`.

Обычное приложение продолжает использовать существующий API. Дизайн-превью — отдельный HTML-вход с локальными фикстурами, визуально обозначенный в верхней панели. Он использует тот же `BackendApp` и общие компоненты; это не второй вариант вёрстки.

## Основные изменения

- Ночная тема, белые основные действия с лёгким бликом, единые типографика и сетка отступов. Маленькие интервалы между родственными карточками и больший padding внутри.
- Онбординг с интересами. Вход в мир двумя сценами; создание героя разделено на выбор трёх направлений практики и образ.
- Лента остаётся главным экраном. Серия перенесена в профиль, подтверждение отправки показывается временной капсулой. Задание формулирует следующий ход и ведёт в редактор.
- Ресурсы, серия, аудитория и семейства навыков используют единый набор объёмных значков. Служебные иконки простые и монохромные.
- Верхнее меню выровнено. Неактивные пункты нижнего меню имеют одинаковые цвета иконок и подписей; выбранный пункт белый.
- Горизонтальная карусель миров поддерживает свайп, мышь, колесо и клавиатуру. Скролл сохраняется, полосы скрыты, края затухают при наличии продолжения.

## Границы механик

В обычном интерфейсе не показываются XP и ручное распределение опыта. Серверные шкалы «Смелость», «Юмор», «В тему», энергия, кристаллы, публикации и ответы сохраняют API-контракты. Остальные выбранные навыки — направления практики с подсказками; отдельные серверные оценки не выдумываются. Подтверждение сохранения поста не означает выполнение квеста. Неизвестный сюжетный исход не превращается в успех.

Обновления backend и общей БД не входят в этот PR. Настоящие серверные ответы нужно отдельно проверить на совместимом DEV вместе с базовым PR #234. Дизайн-превью проверяет только интерфейс и переходы.

## Проверка передачи

- Чистая установка `npm ci`, TypeScript, обычная сборка и отдельная статическая сборка дизайн-превью.
- 18 существующих проверок UI, отображения серверных данных и раздельных черновиков прошли.
- В собранном превью пройдены онбординг, выбор навыков и персонажа, публикация, обсуждение, ответ и обмен кристаллов на энергию. Запросов к API и ошибок JavaScript в этом проходе нет.
- Проверены ширины 390 и 320 px, переключение галереи компонентов. [Снимки экранов](../screens/v8-handoff/).
- Сборщик предупреждает о JS-чанке больше 500 КБ; сборки завершаются успешно. Интеграционные проверки с настоящим сервером в эту передачу не входят.
