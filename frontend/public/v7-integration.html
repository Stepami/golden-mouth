Реки v7

Визуальная система Романа: шрифты, токены, иконки и мобильные компоненты. Скачать токены.

Рабочий API

Каталог, сохранённые истории, регистрация, создание мира, лента, публикации и ответы используют существующий серверный клиент. При обрыве отправки сохраняется прежний идентификатор запроса; сначала проверяется его статус.

Границы

Личка отключена, кристаллы и новая система квестов ещё не подключены. Темы для разговора служат вдохновением, без фиктивного зачёта. Реакции игрока, интересы, размер текста и история результатов сохраняются на устройстве. Цитата пока используется только как контекст.

Сценарный просмотр

Только на DEV параметр ?v7demo открывает автономный прототип с подготовленными NPC-ответами и демонстрационными числами. Он не является заменой API при ошибках и не меняет серверный прогресс.
