# #192: что сейчас отдаём на ревью

04.11.2026. **Один scope — справочники сюжетных автоматов #192.** #195 уже CLOSED и реализована в#222; повторной контентной миграции, новой разметки этой задачи или выкладки здесь нет.

## Предмет повторной проверки Степана

1. Узнаваемость сцен и точность соответствий: «Сумерки» — только первый фильм; «Игра престолов» — все сезоны; максимальная близость с сохранением принятых имён/ников/ID. Замечания19.10/24.10проактуализацию и узнаваемость отражены в текущей версии.
2. Авторы, адресаты, непосредственные родители, факты, якоря и причинность переходов в сохранённом корпусе16ролей. Один оплаченный ход не закрывает два этапа, реплика игрока не создаёт несуществующее согласие NPC.
3. Разделение реально существующего API/данных и предложения исполнителя. Подготовленные тексты/диаграммы не являются доказательством работающего сервера.
4. Совместимость последнего product policy с будущим исполнителем: не импортировать старые числа/названия исходов из корпуса в новую экономику.

Новый дизайн не требует одобрения в этом PR. Расширение длинных историй и конструктор мира отложены; контентный корпус сохраняется для следующих итераций, не блокирует текущий дизайн-релиз.

## Что не считается готовым к реализации по этому PR

- Полная авторская рубрика для каждого квеста и миграция legacy XP в персональный кошелёк.
- Автоматический перенос16старых графов в локальные7дней×3квеста v7. Это разные уровни описания; требуется явное сопоставление и тесты будущего executor.
- Введение методов API, публикация подготовленных NPC-реплик планировщиком или изменение баланса/отношений. [Структурный контракт](proposed-contract.md) остаётся предложением.
- Полная база канона и следующие главы. Исторические249состояний/372пути — результат прежней документной проверки, не текущие серверные тесты.
