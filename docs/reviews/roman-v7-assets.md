## Иконки

Навигация использует исходные чёрные SVG из соседнего чата «Исследовать экспрессивные иконки в Mobbin»: expressive-icons revision-02, goals-messages-navigation и global-navigation от 01.11.2026. Мастер 24×24, отображение 23×23. Стиль — 2D, заливка, чёткая геометрия, простая асимметрия. Новое семейство не рисовалось.

Действия поста — геометрия Heart, MessageCircle, Repeat2 из концепта. Heart path встроен в SocialAction для fill/анимации состояния, координаты исходника сохранены. Внутри поста контур/заливка отличают отсутствие/наличие реакции. Глобальная навигация остаётся залитой.

## Шрифты

TT Norms Pro Condensed и TT Norms Pro Compact найдены по просьбе пользователя в Library/Fonts: Regular, Medium, DemiBold, Bold. Конвертированы из OTF в WOFF2 без изменения геометрии. Установленный шрифт не подтверждает отдельную web/distribution-лицензию; документ с такими правами не найден. Перед публичным production-размещением команда должна проверить свои права. При необходимости исключить восемь TTNorms*.woff2; для `--font-compact` использовать системный sans-serif, для `--font-narrow` — Roboto Condensed в theme.css.

Roboto Condensed — локальный резервный variable-font, metadata указывает Apache License 2.0. Исходные изображения и коммерческий шрифт не перелицензируются этим проектом. Код прототипа подготовлен для передачи команде пользователя.
