# Никнейм, стартовая загрузка и каталог миров

Связанные задачи: #171, #172, #173. Статус: изменения фронтенда для проверки; production не обновлять до просмотра. API и данные БД не меняются.

## Никнейм

Канал и экран «Я» показывали только `player.name`, хотя существующий `player.handle` доступен. Добавлена отдельная строка с одним `@`, имя сохранено. Длинные значения переносятся. Изменение не создает и не меняет никнейм на сервере.

## Проверенный вес production и локальной сборки

Проверка 14 октября 2026: production JS `index-C-nKjhOY.js` имеет размер 1 465 668 байт. Ответ с `Accept-Encoding: gzip, br` не содержит `Content-Encoding`: файл передается без сжатия. Cache-Control immutable на год присутствует. Это отдельный вопрос серверной конфигурации: он требует ревью Stepami и не входит в эту фронтовую выкладку.

| Ресурс | До, raw / gzip | После, raw / gzip |
| --- | --- | --- |
| Стартовый JS | 1465.66 / 428.93 КБ | 465.32 / 141.03 КБ |
| CSS | 23.47 / 5.91 КБ | 23.47 / 5.91 КБ |
| Генератор аватаров | внутри стартового JS | 159.60 / 26.81 КБ, по необходимости |
| Наборы аватаров | все внутри стартового JS | отдельные чанки, по стилю |

Стартовый JS уменьшен примерно на 68% raw и 67% gzip. Общий размер всех чанков не уменьшен: сокращена обязательная загрузка, которая мешала показать первый экран. Стиль выбранного мира загружается при появлении аватара. Для каталога нескольких миров могут понадобиться несколько стилей. Пока идет загрузка, резервируется место с инициалом; при смене мира старый портрет не подставляется новому персонажу.

Изображения не перекодируются: портрет приветствия 18.5 КБ; обложки 640 px — 39.6–60.6 КБ, 960 px — 68.2–122.7 КБ. Существующие responsive/lazy загрузки сохранены. Сравнение с прежним генератором для шести стилей и четырех вариантов профиля подтвердило побайтовое совпадение 24 SVG. Эти размеры не гарантируют конкретного времени открытия: оно зависит от сети, API и устройства.

Проверки: TypeScript и Vite build; браузер 390×844 — приветствие не запрашивает генератор, канал и профиль показывают никнейм и SVG, отсутствуют ненужные стили и горизонтальное переполнение; публикация задания, свободный пост, повтор и недоступное задание проходят прежние проверки. Первый повторный прогон обзоров остановился на подтверждении сохранения черновика; это ожидаемый шаг переключения, а не ошибка картинки. Повторная проверка с подтверждением прошла для всех четырех миров.

## Дополнительный аудит и проверка времени открытия

Минифицированный стартовый JS по карте исходников: React DOM около 207 КБ, группы экранов около 133 КБ, остальное около 125 КБ — общая логика, React и Telegram SDK. Это приблизительная атрибуция уже сгенерированного кода, а не размеры исходников. Все группы экранов пока подключаются сразу: отложенная загрузка необязательных экранов остается следующей возможностью уменьшения стартового веса в #172. Новые зависимости не добавлялись.

Холодный браузер Chrome, viewport 390×844, кеш выключен, пропускная способность 128 КБ/с, задержка 100 мс, Accept-Encoding identity (как в проверенном production без сжатия). API подменен одинаковыми контролируемыми ответами; это замер фронтовой загрузки, не времени генерации или реальной серверной авторизации. Два прогона каждой сборки:

| Показатель | Production-код до изменений | Код с отложенными аватарами и стартовым индикатором |
| --- | --- | --- |
| Готова кнопка первого экрана | 12.05 / 11.98 с | 4.44 / 4.44 с |
| First Contentful Paint | 11.87 / 11.89 с | 0.76 / 0.76 с |
| Передано JS, включая runtime config | 1465851 байт | 465501 байт |

В этом контролируемом тесте первый экран готов примерно в 2.7 раза быстрее. Данные получены до последней правки размещения runtime config и параллельного запроса при входе; эти правки отдельно прошли функциональную проверку. Для production результат дополнительно зависит от сети, авторизации и API; фиксированное время игроку не обещаем.

Индикатор `Загружаем игру…` теперь находится в HTML и доступен до исполнения JS. Через 3 секунды появляется пояснение длительного ожидания, через 15 — ссылка обновления страницы. Runtime config перенесен после разметки индикатора, но перед выполнением приложения: его загрузка не препятствует разбору этой разметки. Проверена искусственная задержка и основного JS, и runtime config, затем правильная замена индикатора приложением. Это покрывает ожидание до запуска React, а не все сценарии #161.

После успешного /me существующие GET /worlds и /invitation выполняются параллельно, вместо двух последовательных ожиданий. Контракт, бонус и серверный код не меняются; ошибки остаются ошибками. Браузерная проверка с задержанным /worlds подтвердила, что /invitation начинается до завершения /worlds. Это убирает одно последовательное ожидание при входе существующего игрока.

Портрет и WebP не менялись. На холодном приветствии наборы аватаров не скачиваются; при переходе нужны только используемые стили. Годовой immutable-кеш статики уже включен; runtime config no-store и HTML no-cache соответствуют обновлению сборки. Внешних шрифтов нет. Самый большой отдельный неиспользованный резерв — HTTP-сжатие: для текущего стартового JS оценка gzip около 141 КБ вместо 465 КБ raw. Его включение относится к серверной конфигурации, требует отдельного PR с ревью Stepami и здесь не выполнено. Новая задача автоматически не создается.

По поручению пользователя из AgeRuleNote убраны слова «графическое насилие». Это только формулировка интерфейса; правила генерации и модерации бэкенда не менялись.

## Предложение для миров — сначала обсуждение

Референс Status: главная с Featured Worlds / Popular, компактные горизонтальные карточки с картинкой, короткой завязкой и персонажами; отдельная кнопка создания своего мира. Сильная сторона — каталог воспринимается как выбор истории, а не форма настройки.

Предлагаемый порядок для «Рек»:

1. Заголовок «Миры», понятный возврат к предыдущему экрану.
2. При наличии игры — «Продолжить историю»: текущий мир, обложка, имя канала и действие «Продолжить». До первой игры блок отсутствует.
3. «Выбрать новую историю»: существующие пресеты, короткая уникальная завязка и герои. Для четырех пресетов достаточно одной секции, без искусственных рейтингов и дублирования карточек по категориям.
4. «Мои миры», если они есть: собственные миры появляются сразу, без временного исчезновения или промежуточного списка.
5. Отдельный вход «Создать свой мир». Пока закрыто — существующий прогресс и текст «Откроется после 500 подписчиков в одном канале или после первого поста приглашённого друга». После открытия — активное действие создания; поздравление остается отдельным моментом достижения.

Карточка нового мира сначала открывает обзор: игрок понимает сюжет и условия до переключения. «Продолжить» возвращает в канал текущего мира. Сохранение черновика при смене мира остается действующим. Не переносить из Status неподтвержденные числа популярности, Plus и платежные элементы.

#173 пока содержит анализ и предложение. Новый каталог не реализуется и не выкладывается до обсуждения этого предложения с пользователем.
