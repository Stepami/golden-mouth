# Никнейм, стартовая загрузка и каталог миров

Связанные задачи: #171, #172, #173. Статус: изменения фронтенда для проверки; production не обновлять до просмотра. API и данные БД не меняются.

## Никнейм

Канал и экран «Я» показывали только `player.name`, хотя существующий `player.handle` доступен. Добавлена отдельная строка с одним `@`, имя сохранено. Длинные значения переносятся. Изменение не создает и не меняет никнейм на сервере.

## Проверенный вес production и локальной сборки

Проверка 14 октября 2026: production JS `index-C-nKjhOY.js` имеет размер 1 465 668 байт. Ответ с `Accept-Encoding: gzip, br` не содержит `Content-Encoding`: файл передается без сжатия. Cache-Control immutable на год присутствует. Это отдельный вопрос серверной конфигурации: он требует ревью Stepami и не входит в эту фронтовую выкладку.

| Стартовый JS | 1465.66 / 428.93 КБ | 465.35 / 141.04 КБ |
| CSS | 23.47 / 5.91 КБ | 23.47 / 5.91 КБ |

| Наборы аватаров | все внутри стартового JS | отдельные чанки, по стилю |

Стартовый JS уменьшен примерно на 68% raw и 67% gzip. Общий размер всех чанков не уменьшен: сокращена обязательная загрузка, которая мешала показать первый экран. Стиль выбранного мира загружается при появлении аватара. Для каталога нескольких миров могут понадобиться несколько стилей. Пока идет загрузка, резервируется место с инициалом; при смене мира старый портрет не подставляется новому персонажу.

Изображения не перекодируются: портрет приветствия 18.5 КБ; обложки 640 px — 39.6–60.6 КБ, 960 px — 68.2–122.7 КБ. Существующие responsive/lazy загрузки сохранены. Качество SVG аватаров также сохранено. Эти размеры не гарантируют конкретного времени открытия: оно зависит от сети, API и устройства.

Проверки: TypeScript и Vite build; браузер 390×844 — приветствие не запрашивает генератор, канал и профиль показывают никнейм и SVG, отсутствуют ненужные стили и горизонтальное переполнение; публикация задания, свободный пост, повтор и недоступное задание проходят прежние проверки. В одном повторном прогоне обзоров ожидание загрузки картинки второго мира истекло: это не считается успешной проверкой всех картинок и требует дополнительного исследования перед закрытием #172.

## Предложение для миров — сначала обсуждение

Референс Status: главная с Featured Worlds / Popular, компактные горизонтальные карточки с картинкой, короткой завязкой и персонажами; отдельная кнопка создания своего мира. Сильная сторона — каталог воспринимается как выбор истории, а не форма настройки.

Предлагаемый порядок для «Рек»:

1. Заголовок «Миры», понятный возврат к предыдущему экрану.
2. При наличии игры — «Продолжить историю»: текущий мир, обложка, имя канала и действие «Продолжить». До первой игры блок отсутствует.
3. «Выбрать новую историю»: существующие пресеты, короткая уникальная завязка и герои. Для четырех пресетов достаточно одной секции, без искусственных рейтингов и дублирования карточек по категориям.
4. «Мои миры», если они есть: собственные миры появляются сразу, без временного исчезновения или промежуточного списка.
5. Отдельный вход «Создать свой мир». Пока закрыто — существующий прогресс и текст «Откроется после 500 подписчиков в одном канале или после первого поста приглашённого друга». После открытия — активное действие создания; поздравление остается отдельным моментом достижения.

Карточка нового мира сначала открывает обзор: игрок понимает сюжет и условия до переключения. «Продолжить» возвращает в канал текущего мира. Сохранение черновика при смене мира остается действующим. Не переносить из Status неподтвержденные числа популярности, Plus и платежные элементы.

#173 пока содержит анализ и предложение. Новый каталог не реализуется и не выкладывается до обсуждения этого предложения с пользователем.
