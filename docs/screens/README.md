### DEV-прототип быстрой настройки · 13.10.2026

Последний слой `journey_v19.py` заменяет каталог обложками и сокращает путь пресета до обзора, персонажа и драмы. Предыдущий четырёхшаговый редактор доступен через «Расширенные настройки».

| Экран | Назначение |
|---|---|
| 01-3_world | Обложки миров, продолжение игры, создание своего мира |
| 01-3b_world_overview | Описание, завязка и герои выбранного пресета |
| 01-4_channel | Свой персонаж или готовый герой |
| 01-4b_world_setup | Градус драмы с объяснениями, голос предустановлен |
| 05-7b_own_world | Быстрая идея своего мира; расширенный режим сохраняет полный редактор |
| 05-7c_world_preview | Демо-лента собственного мира без сохранения на сервере |

Демонстрационное наполнение отмечено в интерфейсе; настоящая AI-генерация не подключена. Backend-задача будет оформлена после одобрения.

DEV-вариант `05-12_world_advanced`: единый расширенный редактор с раскрываемыми разделами; открывается существующими маршрутами настройки, отдельного маршрута API не вводит. Основной источник макетов — journey_v20.py; journey_v25.py добавляет «Персонализацию аватарки» в раздел персонажа и общие настройки. Первые ходы, каталог и настройки мира также актуализированы этим слоем.


DEV-проход `journey_v21.py`: темы поста видны сразу, профиль объясняет энергию и открытие своего мира. Выбранный герой сохраняет место в списке; личные настройки показываются как компактный профиль. Жалобы скрыты до полноценного разбора на сервере. Чужие посты не открывают редактор ответа; свои определяются по GET /posts/mine. Обновление ленты показывает загрузку и наличие новых постов. DEV-прототип настройки доступен только с параметром `devtools`, вне обычного пути. Реферальные статусы и уведомления о друге не имитируются; используется только подтверждённый сервером доступ. Числа первого экрана — пример игры, баланс и стартовые значения не изменены.


DEV-проход `journey_v22.py`: пример канала Маши с сгенерированным портретом; первая история с уже сохранённой обложкой выбранного мира. Каталог компактно объясняет два условия открытия своего мира. Подсказка ответа выделена цветом и закрывается отдельно; в заголовке один выход в ленту. В профиле две компактные статистики и отдельное задание. Основные сведения о мире видны сразу. Правила кратко сформулированы положительно, серверные ограничения не меняются. Выполненное задание показывается в итоге отдельно от подробностей только после сравнения подтверждённых состояний wants до и после публикации; текст поста не используется для самостоятельного зачёта. Серверные ribbons также видны вне раскрывающегося блока.
