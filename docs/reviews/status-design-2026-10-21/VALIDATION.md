# Проверка артефактов, 21.10.2026

Это проверка исследования и эскизов. Приложение не изменялось, поэтому она не доказывает выполнение критериев реализации #205.

- `origin/master` получен перед работой; базовый коммит `cbc26b9`. Ветка работы отдельная.
- Корневые правила, `frontend/AGENTS.md`, `screen-check` и `issue-spec` прочитаны. Проверены открытые issues/PR: дубля общей фронтенд-задачи нет. Создана только запрошенная задача #205, без автоматического запроса ревью и без новых backend-issues.
- `npm ci --ignore-scripts` и сборка через `frontend/scripts/screens.sh` завершились успешно. Lockfile и исходники фронтенда не менялись. Генерируемый `tsconfig.tsbuildinfo` восстановлен после сборки. Вывод npm о существующей зависимости вне scope этого предложения не исправлялся.
- Локальные JS/CSS сопоставлены с публичными ресурсами приложения: байты совпали. Контрольные суммы и ограничения проверки записаны в README.
- Снимки текущих экранов выполнены headless Chrome по методу `screen-check`, с mock runtime-конфигурацией, которая восстановлена после съёмки. Production API не использовался для записи. Снимки сняты в 390×844 с плотностью 2, часть уменьшена из плотности 3. Файлы PNG — 780×1688.
- Для непустого канала/ленты только в локальной собранной статику перед модулем приложения добавлено заполнение ключа `reki:demo-posts:v2:<fixture-player>:it` вымышленным постом. Исходники приложения не патчились. Без такой фикстуры канал корректно показывает Home; это не баг.
- Эскизы отрисованы из `proposals.html`, варианты `?screen=channel|result|compose|empty|error|profile|story`, 390×844. Все семь просмотрены визуально: текст не обрезан, CTA и подписи доступны, панель результата не перекрывает объяснение. Для каждой PNG проверены размеры/декодирование. Полный HTML — документ для браузера, а не route игры; переходы в нём демонстрационные.
- В эскизах проверено только основное состояние на 390×844. Реальная клавиатура, 320 px, крупный шрифт, screen reader, фокус и сеть остаются критериями будущей реализации. Их прохождение здесь не заявляется.
- Кадры Status ссылаются на закреплённый коммит `22a1f6d` и соответствуют ID из manifest; ссылки ведут на конкретные оригиналы.
- SQL воспроизводит текущие определения продуктового дашборда. Время среза и точные запросы сохранены с агрегатными результатами, без индивидуальных ID и содержимого постов. Запрос coverage намеренно перечисляет виды событий до поведенческого фильтра.
- Проверены относительные ссылки документа/изображений, уникальные ID HTML, синтаксис JS, отсутствие сетевых вызовов в HTML и diff на пробелы. Проверка секретов выполнена по всем отслеживаемым файлам перед PR.

Для повторного просмотра можно открыть `proposals.html` напрямую; внешних шрифтов, скриптов и изображений он не загружает. PNG открываются без HTML. Для повторной съёмки текущей вёрстки используется существующий `frontend/scripts/screens.sh`; режим backend в локальном runtime-конфиге временно заменяется на mock и восстанавливается после проверки. Не направлять этот сценарий в production и не считать демонстрационные показатели реальными событиями игроков.
