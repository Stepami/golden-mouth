# Знак «Реки»: два потока

Согласовано 14.10.2026: вариант 02 последней серии эскизов. Две розово-сиреневые волны обозначают действие игрока и отклик мира; изгиб между ними связывает название с течением реки. Знак универсален для разных игровых миров, без портрета отдельного героя.

Исходник: `assets/reki-wave-logo-v2.png`. Аватарка бота: `assets/reki-bot-avatar.jpg`, 640×640. Набор веб-иконок в `frontend/public/` получен из одного исходника: favicon 16/32/48 px, Apple touch icon 180 px и Android icons 192/512 px. Тёмный фон и свободные поля сохраняются при круглом кадрировании Telegram. ICO содержит три размера.

Иконки и manifest имеют версию `wave-2` в URL, чтобы браузер запрашивал обновлённые файлы. Имя установленного приложения — «Реки», цвет темы — `#0E0E13`.

Знак создан встроенным imagegen. Финальный промпт: выделить только центральный вариант 02 из согласованного листа, сохранить две формы и розово-сиреневый градиент, центрировать на квадратном тёмном фоне с полями для круглой аватарки; без текста и новых элементов. Размеры для использования получены системным `sips`, ICO упакован из PNG без изменения формы.

Публикация аватарки и веб-иконок согласована отдельно. Это не разрешение на публикацию нового входного экрана или изменение игровых механик.
