# Короткий цикл и сюжетные пакеты

Утверждено 08.11.2026 по #205: четыре мира, по пять ролей и 20 квестов в каждом. Это целевая документация для реализации; она не объявляет готовность общего DEV.

Один системный квест может занимать несколько ходов. Новая часть прогресса сохраняется и развивает проявленные навыки сразу; без нового прогресса по текущему квесту рост навыков равен нулю. После финала лента остаётся свободной, навыки растут за новые подтверждённые взаимодействия. Повторы не дают новый рост. Для первого теста 09.11 согласованы +10 и пороги уровней 1–10: 0 / 10 / 30 / 60 / 100 / 150 / 210 / 280 / 360 / 450. [баланс навыков от 09.11](SKILL-BALANCE.md).

Каждая роль имеет три своих навыка. Главная цель постоянна, роль не подменяется по ходу. NPC видны сразу; до их подписки личная динамика статична. Люциус и совет остаются за сценой. Массовые подписчики не становятся сюжетными NPC.

Нет XP, ручной прокачки, карты и личных чатов. Энергия общая: максимум 10, действие стоит 1, восстановление +1 за 10 минут. Награды только кристаллы: за уровень навыка, сюжетные этапы и серии. Для Хогвартса приняты этапы 1, 3 и 4; суммы и повторное прохождение ещё открыты.
