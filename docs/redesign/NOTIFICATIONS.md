# Уведомления — компонент дизайн-системы

Решено владельцем продукта 11.11.2026 после просмотра DEV. Реализация: `frontend/src/v7/ui/ActivityItem.tsx`; образец — «Уведомление / ActivityItem» на экране `#system`.

- Заголовок — максимум две строки.
- Превью сообщения — максимум три строки, остаток скрывается многоточием.
- Прочитанная запись остаётся в списке, индикатор непрочитанного исчезает.
- Нажатие на запись открывает исходную публикацию с полным ответом; на запись серии — подробности серии.
- Один компонент применяется в списке уведомлений и в образце дизайн-системы.
- Ширины 320 px и 390 px, desktop и увеличенный текст проверяются без горизонтального переполнения.
- Лента уведомлений не показывает вымышленные события, авторов реакций или начисления. Доступность событий определяется сервером.

Кнопка серии в шапке открывается целиком по нажатию и не содержит стрелки раскрытия. Подробная карточка серии остаётся в профиле.
