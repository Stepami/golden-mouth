# Просмотр своих постов

Решено 11.11.2026: вверху ленты текущего прохождения есть переключатель «Все / Мои посты».

«Все» показывает общую ленту. «Мои посты» загружает публикации игрока через существующий `GET /posts/mine` с `worldId` текущего прохождения. Фильтрация по автору и порядок от новых к старым обеспечиваются сервером; имя персонажа не используется для отбора. Старые публикации догружаются по курсору кнопкой «Показать ещё».

Карточки сохраняют реакции, число ответов и переход к обсуждению. В пустом списке — «Здесь появятся твои посты» и кнопка «Написать пост». При ошибке загрузки доступны объяснение и повтор. Возврат к «Все» сохраняет загруженную общую ленту. У каждого прохождения свой список.
