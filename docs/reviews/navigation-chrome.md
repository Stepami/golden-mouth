# Единая навигация приложения — #173

Главные экраны: Миры, Канал, Лента, Я. На каждом одинаковое нижнее меню, активная вкладка отмечена визуально и aria-current. До создания профиля меню не показывается.

Верхняя панель: общий TopBar, отступы 16px, минимальная высота 64px, действия 44px. Заголовок слева, действие справа. Энергия — единая компактная плашка; ссылки не оборачиваются в декоративную плашку. Канал содержит имя, ник и название истории; высота может увеличиваться для этих данных.

Редакторы и комментарии: вместо меню снизу панель публикации/ответа; верхний возврат сохраняет контекст. Итоги — крестик возврата в канал. Не размещать одновременно меню вкладок и панель ввода в одной нижней области.

Ссылки «Миры» в шапке канала и профиле убраны: раздел постоянно доступен в нижней навигации. Safe-area учитывается, контент имеет запас снизу.

Проверка: реальные шаблоны с mock API, браузер 390×844 и 320×844, Миры/Канал/Лента/Я/редактор: одно меню, одна активная вкладка, нет горизонтального переполнения и ошибок JavaScript. Вариант показан на DEV; пользователь согласовал production 2026-10-14.
