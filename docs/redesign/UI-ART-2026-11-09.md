## Предметные значки

Файл: `frontend/public/assets/game-art/icons-gloss.png`. Общий прозрачный атлас 4×4, используется через `ui/GameArt.tsx`; компонент ограничивает область каждой ячейки и задаёт размер. Первоначальный матовый вариант переработан по обратной связи: более глубокие цвета и немного глянца. Старые ювелирные ресурсы больше не используются RewardArt.

| Ряд | Слева направо |
|---|---|
| 1 | Энергия, кристалл, серия, аудитория |
| 2 | Подарок, усиление, смелость, юмор |
| 3 | Контекст, дипломатия, эмпатия, аргументация |
| 4 | Точность, знания, свой голос, направление |

Навыки объединены в семейства по смыслу; сопоставление находится в `GameArt.tsx`. Нового начисления или отдельных серверных шкал это не создаёт. Предметная простота изучена на [Airbnb в Mobbin](https://mobbin.com/screens/49f0730c-6356-476a-b481-b679952db447); сами формы сгенерированы для «Рек», не скопированы из Airbnb.

Again exact 4 columns and exact 4 rows on a transparent square canvas, all 16 objects separate and evenly centered.

### Финальная правка материала

```text
Refine this existing 4x4 icon atlas for a premium BLACK user interface. Keep EXACTLY the same 16 symbols, shapes, cell layout, cell order, grid alignment, and overall simplicity. Do not add more detail, ornaments, badges, text or parts.
The current finish is too chalky and pale. Replace the matte pastel material with richer, confident satin-gloss ceramic / lacquered polymer. Deeper amethyst purple, clean teal and cyan blue, warm coral orange, richer rose, and pearl-white neutrals. Colors should be saturated enough to read on #101010, yet restrained. Add ONE clean soft specular highlight on each main shape, a subtle bright edge rim, and gentle form shading. Premium carefully crafted product icons, minimal and tactile, not cheap toys. No chrome frames, no gemstones, no glass refraction, no metallic rainbow highlights, no busy reflections. Whites should feel luminous porcelain, not dirty gray or beige.
Preserve the transparent background. Leave clean fully transparent space around every object. Remove all stray noise and faint texture from the transparent gaps. Each object must stay wholly within its original cell. This is the same exact atlas with improved rich color, contrast and very slight polish, not a redesigned grid.
```
