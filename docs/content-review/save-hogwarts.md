# Обновление «Школы чародеев» в «Спасти Хогвартс»

Решено 14.11.2026, Refs #205: отдельный пятый мир не добавлять. Обновить существующий шаблон `aec9494b-4118-4525-8458-e85d759c8dd9`: название «Спасти Хогвартс», завязка о банкротстве школы и споре о будущем замка. В каталоге остаются четыре мира.

Источники из репозитория:

- [Актуальные завязка, роли и первые действия](https://github.com/Stepami/golden-mouth/blob/5e6e050/frontend/src/v7/story/roleScenarios.json), раздел «Спасти Хогвартс».
- [Утверждённый пакет](https://github.com/Stepami/golden-mouth/blob/1b6eee7/docs/redesign/short-cycle/HOGWARTS.md), утверждён 08.11, уточнён 09.11.

Имена берутся из пакета: Гарри Поттер, Гермиона Грейнджер и Рон Уизли. Прежние ID и никнеймы сохраняются: `gosha` / `gosh`, `georgina` / `__curly_wit_`, `roman` / `roman`. Для коммерческого проекта добавляется Драко Малфой (`draco`). Персонаж игрока при выборе готового героя исключается из собеседников существующей формой выбора.

| Выбор | Постоянная цель |
|---|---|
| Гарри Поттер | Снова открыть Хогвартс. |
| Гермиона Грейнджер | Добиться устойчивой и этичной школы, учитывающей разные культуры. |
| Рон Уизли | Сохранить доступ к обучению для небогатых семей. |
| Драко Малфой | Закрыть школу и превратить замок в прибыльный бизнес. |
| Свой персонаж | Повлиять на решение совета: сохранить школу или открыть отель. |

События первого курса остались в прошлом героев. Совет пока не одобрил ни один проект; финансирование не подтверждено. Люциус и совет действуют за сценой, без собственных каналов и ответов игроку. Фиксированную сумму сбора из ранней пробы не переносим: обещание поддержки не означает полученные деньги.

Миграция 2.7.5 обновляет только активный публичный шаблон в `world_templates`, сохраняя его ID, ник канала, ID и никнеймы существующих героев. Другие шаблоны и уже созданные личные истории игроков не изменяются. При повторном выполнении дубликаты героев не добавляются.

Лендинг `?landing=hogwarts` и одноимённая карточка разводящей выбирают этот шаблон по прежнему ID. Изменения главной и отдельных посадочных согласуются и выпускаются отдельно. Везде новый игрок после входа проходит возраст и согласие, затем обзор выбранного мира.

Это перенос контента в текущую схему `World` и старый интерфейс production. Двадцать квестов, сюжетный автомат, новые навыки и экономика из пакета редизайна этим изменением не реализуются. Действующие возраст, модерация, энергия, навыки и награды берутся из текущих `game-flow.md` и `balance.json`; сложность сохраняется.

Для новой настройки во всех готовых мирах первым выбран первый доступный герой; «Свой персонаж» расположен последним. Явно выбранная роль сохраняется в черновике. В обзоре показывается цель этой роли (по умолчанию — первого героя), а не цель своего персонажа для всех. Для своего персонажа Хогвартса заранее заданы цель, начальная ситуация и первое действие.

Предпросмотр через `?screen=...` не авторизует посетителя. Только в DEV без подтверждённой личности он работает без сохранения и открывает явно помеченный пример истории. Обычный онбординг начинается после входа, возраста и согласия; повторной авторизации на шаге настройки мира нет.

Видимые биографии сокращены до характера и интересов героев. Редакторские оговорки о подаче бедности и полномочиях совета не показываются как биография. Отдельный фильтр перефразирования или новый модерационный фильтр не добавлялся; действующая модерация backend сохраняется.

Основная кнопка настройки — яркая «Начать историю», которая сохраняет мир и открывает историю. Отдельной кнопки примера в обычной настройке нет; статичный предпросмотр остаётся только служебным DEV-экраном. Пояснения «Для сохранения игры нужно войти» в обычном онбординге нет: вход уже пройден. Без сохранения работает только явно помеченный служебный DEV-предпросмотр.
Параметры служебных экранов `screen`/`gallery` действуют только в DEV. Production-сборка не открывает через них выбор персонажа или настройку мира до обычного входа и возрастного онбординга.
