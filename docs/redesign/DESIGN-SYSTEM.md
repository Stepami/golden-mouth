## Применение

| Область | Правило |
|---|---|
| Основа | Белый фон, ink #171918, muted #626863, серые поверхности; lime #e8fb6d — основное действие. |
| Семантические цвета | Энергия #8325ff, кристаллы #43f9ff, прогресс #ffe310, цель #ff3366. Цвет дополняет подпись/значок, не заменяет их. |
| Шрифты | TT Norms Pro Compact — основной текст; TT Norms Pro Condensed — заголовки. Использовать переменные темы и локальные файлы. |
| Размеры | Оболочка максимум430px, gutter20px, базовый шаг4px, touch target44px. Перенос текста и масштаб200% не должны перекрывать действия. |
| Карточки и кнопки | Общие Button/Chip/WorldCard/Avatar; состояния default/selected/disabled/busy/focus/error. Disabled означает отсутствие действия. |
| Аватары | Круглая обрезка фото/рисунка, object-fit:cover, инициалы при отсутствии изображения. Экспериментальные 3D-портреты не входят в релиз до фиксации кода. |
| Верхняя панель | Единая группа: мир/аудитория, энергия, кристаллы, персонаж; серия/подарок/бустеры без внутреннего разделителя. |
| Редактор | Сюжет: текущий квест, награда и выбор имеющегося бустера. Песочница: эти блоки скрыты, текст сохраняется. Публикация только по нажатию. |
| Профиль | Аудитория → цель ниже верхних бустеров → карта дней → компактный XP/распределение. Один выбранный день раскрывает три шага. |
| Результат | Ожидание, сохранённый пост/комментарий и оценка квеста — разные состояния. Причина исхода, XP и аудитория читаются раздельно. Не показывать автоматическую прокачку навыков как новый ручной XP. |
| Движение | Анимация отвечает на действие: награда, подарок, выбранное состояние. Reduced motion отключает декоративное движение; длинное описание можно прокручивать вручную и поставить на паузу. |
| Достоверность | API-ошибка не превращается в фиктивный успех. Неизвестное значение «—»; локальная проба подписана. Серверная аудитория и локальный инвентарь не смешиваются в один неподписанный баланс. |

## Приёмка интерфейса

Короткий проход на точном релизном артефакте: вход Telegram/браузер → прежний мир → пост → ожидание/результат → комментарий → возврат/перезагрузка → профиль/настройки. Проверить узкий экран, клавиатуру/фокус, крупный текст, безопасные зоны и отсутствие перекрытия кнопок. Мокапы, галерея и успешная сборка этот проход не заменяют.
