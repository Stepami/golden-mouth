# Верхняя часть каталога и поиска

Решено владельцем продукта 11.11.2026 после сравнения с production-сборкой 8dd27b5.

- Оба экрана используют ScreenHeading: одинаковые шрифт, боковые и верхние отступы.
- У главной под заголовком находятся «Мои миры», у поиска — поле ввода. Каждый блок занимает естественную высоту. Минимальная высота ради выравнивания фильтров между разными экранами не задаётся.
- Поиск сохраняет компактную компоновку прежней production-версии. Жанровые фильтры и сетка миров идут сразу после его поля.
- Карточки миров, их ширина, отступы и размеры обложек не меняются ради выравнивания.
- Если сохранённых миров пока нет, пустой блок «Мои миры» не создаётся.
- Переключение нижних вкладок заменяет текущую ветку навигации. Повторное нажатие не складывает одинаковые экраны в историю.
- На корневых экранах «Главная», «Поиск», «Профиль» системная кнопка Telegram «Назад» скрыта. Во вложенных экранах возврат сохраняется; «Написать» открывается как отдельное действие с возвратом.
